# Reading the buyer — the demand-side calibration behind this repo's language

> **Public edition.** Re-authored from a private market-calibration source that tracks what Marketing / GTM analytics hiring managers are currently asking for. The private version carries the full posting corpus, per-posting notes, and source routes; this edition keeps the judgment: positioning language is a measured decision, re-calibrated in dated rounds — never a vibe.

## The judgment, in one screen

**What this practice prevents:** positioning by echo — describing yourself in the vocabulary you learned instead of the vocabulary the buyer currently uses for the problem they are hiring away. Textbook terms read as coursework. Last year's AI language reads as noise. A surface that was never tested against live demand is a message-market-fit assumption, not a strategy.

**The mechanism:**

```text
corpus of real postings (entry-level, adjacent titles, dated rounds)
  -> recurring demand axes (what is actually asked for, and how often)
  -> buyer clustering (who is buying which version of the role)
  -> language dosing on my own surfaces (what leads, what is banned, what stays boundary-checked)
  -> re-calibration in a dated round when the market moves
```

This is the same discipline the [evidence ledger](evidence-ledger.md) applies to numbers, applied to vocabulary: dated reads, visible drift, no silent confidence.

## Why this is the strategy, not a garnish

Segmentation, message architecture, and channel choice are usually claimed in a portfolio as past-tense war stories. Here they are running decisions with receipts: the segments are real buyer clusters read from live demand; the message architecture is enforced by claim ceilings and an exit gate; the channel mix — application, outreach, this repository, the live pipeline page — exists because the demand read said walkable proof is what buyers ask to see; whether it converts better is this cycle's open test. When the next dated round moves, the language moves with it, and the drift is visible instead of silent.

The per-opportunity version of this same read — one posting, one reader, one claim ceiling — is [`jd-loop-routing`](../skills/jd-loop-routing/SKILL.md). This document is the market-level layer above it.

## Boundaries

- This is small-n, personal-use market research for one candidate's go-to-market. It is **not** commercial market-research, competitive-intelligence, or syndicated-data ownership.
- Counts are dated snapshots of one round's corpus, kept with the same policy as the [evidence ledger](evidence-ledger.md): a new round re-dates or overturns any row.
- The practice predates this repository, but this is its first published round — the visible drift the mechanism promises starts accruing from the next dated round.
- No posting is quoted at length, named, or identifiable; frequencies describe the corpus, not any employer.
- Buyer clusters describe reading strategy, not lead scoring — a posting is a demand signal, not a scored lead.

# Evidence ledger — dated snapshots from the running system

> **Public edition.** Exact numbers rot: a count that was true at publish time silently stops being true while the prose around it still reads confidently. This repo's rule: evergreen copy carries floors and mechanisms; exact counts live here, dated, so drift is visible instead of silent. When a number in this ledger disagrees with prose elsewhere in the repo, the ledger wins and the prose gets fixed. Read it as the system's metric dictionary: every figure carries a definition, a date, and a measurement boundary — and when an outcome number earns a public row, it lands here first.

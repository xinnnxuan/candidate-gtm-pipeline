# 03 · Positioning & Messaging

**What this stage is for:** making the right proof easy to see — without overstating it. The stage translates true candidate evidence into one specific reader's language, under the claim ceiling stage 02 wrote, and refuses to let wording patch a structural gap.

| | |
|---|---|
| **Inputs** | The routing brief (binding) · the candidate's true evidence, opened only after the buyer read is stable |
| **The decision** | *Which true evidence reduces this buyer's hiring risk?* |
| **Handoff** | Buyer-ready evidence with explicit gaps, graded by the exit gate, to [04 · Marketing Operations](../04-marketing-operations/README.md) |
| **Human authority** | Release approval is the operator's; the grader's pass is an input to that call, not a substitute |

## Skills at this stage

| Skill | Role | The judgment it owns |
|---|---|---|
| **[Buyer-Ready Proof](buyer-ready-proof/SKILL.md)** | lead | Translating real evidence into one reader's language without borrowing what can't be defended — exit-gated by [a 7-check grader](buyer-ready-proof/graders.md) that points, never re-edits |
| [Marketing Reframe](marketing-reframe/SKILL.md) | related | Which bounded Marketing / GTM capability a true mechanism can honestly claim, at which evidence level |

**Recommended start:** open [the lead contract](buyer-ready-proof/SKILL.md), then read [a resume line that failed the gate — and the fix](../../examples/resume-draft-fail-and-fix.md): same work, same honesty, different defensibility.

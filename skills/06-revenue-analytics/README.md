# 06 · Revenue Analytics

**What this stage is for:** making sure results actually change something — and that noise doesn't. Every outcome, loss, and session lesson passes a triage whose default answer is *don't write*: only repeated or high-cost evidence earns a change to targeting, proof, or follow-through rules. This is the stage that closes the loop back into 01–03.

| | |
|---|---|
| **Inputs** | Outcomes and losses from stage 05 · the session's own corrections, rework, and insights |
| **The decision** | *Which result should change the next rule or allocation?* |
| **Handoff** | A decision readout plus proposed changes, written back into [01 · Market Research](../01-market-research/README.md), [02 · Audience Strategy](../02-audience-strategy/README.md), and [03 · Positioning & Messaging](../03-positioning-messaging/README.md) |
| **Human authority** | Promotion into a standing rule is the operator's call; a single run changes no rules |

**繁中摘要** — 這一站決定「結果要不要改變規則」。預設答案是不寫回：單一回覆、沉默或拒絕只是觀察，不自動成為 pattern；候選學習要通過四題（會重複嗎、已被涵蓋嗎、不寫的代價、最小修改讓系統更短更穩嗎）才升格為長期規則，且以吸收式改寫落地、不疊加條文。通過的變更回頭修正 01–03 的 targeting、proof 與規則——這就是閉環。
